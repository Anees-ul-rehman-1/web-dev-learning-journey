Loops in JS

Loops ar used to execute a piece of code again & again

for loop

The for loop is used when you know how many times you want to execute a block of code.


     Syntax
     for(initialization; condition; update) {
     // code to execute
     }

     Example
     for (let i = 1; i <= 5; i++) {
     console.log("Anees Ul Rehman");
     }
     Output
     Anees Ul Rehman
     Anees Ul Rehman
     Anees Ul Rehman
     Anees Ul Rehman
     Anees Ul Rehman

How it Works

  • Initialization → Runs once before the loop starts.
  • Condition →Checked before every iteration.
  • Update → Runs after each iteration.

Common USe Cases

  • Repeating an operation a specific number of times.
  • Iterating through indexes.
  • Processing array elements when an index is required.

Infinite Loop

An infinite loop is a loop that never terminates because its never becomes false. 


     Example
     while (true) {
        console.log("Runing...");
     }
    <!-- The loop will continue indefinitely. -->
    
    
Common Cause

     For example
     let i = 1;

     while (i <= 5) {
        console.log(i);
     }
     <!-- Here i is never updated, so i <= 5 always remain true -->

     for (let i = 1; i >= 0; i++) {
        conosle.log("Anees Ul Rehman")
     }

Important

Always make sure that a loop has a valid way to eventually make its condition false.

while loop

The while loop repeatedly executes a block of code as long as the condition remains true.


     Syntax
     while (condition) {
     // code to execute
     }

     Example
     let i = 1; 
     while (i <= 5){
     console.log(i);
     i++;
     }
     Output
     1
     2
     3
     4
     5

Important

  • The condition is checked before the loop body executes.
  • If the conditoin is false from the beginning, the loop will not execute even once.

do...while loop

The do...while loop executes the block of code at last once, and then checks the condition.


     Syntax
     do {
        // code to execute
     } while (condition);
     Example
     let i = 1;
     do {
        console.log(i);
        i++;
     } while (i <= 5);
     Output
     1
     2
     3
     4
     5

Important Different

Unlike the while loop, the do...while loop executes its code before checking the condition.


     let i = 10;
     do {
        console.log(i);
     } while (i <= 5);
     Output
     10

Even though i <= 5 is false, 10 is printed once.

for...of Loop

The for...of loop is used to iterate over the values of iterable objects, such as arrays and strings.


     for (let value of iterable) {
        // code to execute
     }

     Example with an Array
     const fruits = ["Apple", "Mango", "Banana"];
     
     for (let fruit of fruits) {
        console.log(fruit);
     }
     Output
     Apple 
     Mango
     Banana
     Example with a String
     const word = "Hello";

     for (let character of word) {
        console.log(character);
     }

     Output
     H 
     e 
     l 
     l 
     o

key Point

for...of gives you the value of each element.

Array → for...of → Values

for...in loop

The for...in loop is primarily used to iterate over the keys (property names) of an object.


     Syntax
     for (let key in object) {
        // code to execute
     }

     Example
     const student = {
        name: "Anees Ul Rehman",
        age: 18,
        couse: "JavaScript"
     }

     for (let key in student) {
        console.log(key);
     }
     Output
     name
     age
     course

Accessing Values

You can use the key to access its corresponding value:


     for (let key in student) {
        console.log(key, student[key]);
     }
     Output
     name Alex
     age 18
     course JavaScript

Key Point

for...in gives you the keys of an object.

object → for...in → Keys
