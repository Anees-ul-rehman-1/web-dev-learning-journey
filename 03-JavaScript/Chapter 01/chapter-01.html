Chapter 01 — JavaScript

What is JavaScript

JS is a programming language. We use it to give instructions to the computer — turning static pages into things that can think, react, and calculate.

Input (code) → Computer → Output

Our 1st JS Code

Console.log is used to log(print) a message to the console

             
console.log("Apna College"); // prints a message to the console

Variables in JS — containers for data

Think of a variable as a labeled box. The label is the variable name, the thing inside is the value. What kind of box you use — var, let, or const — decides whether you can swap what's inside, or relabel it entirely.

var

Old-School box

— Can be re-declared

— Can be updated

— Global scope

let

Flexible box

— Can't be re-declared

— Can be updated

— Block scope

const

Sealed box

— Can't be re-declared

— Can't be updated

— Block scope

Variable Rules

  • Variable names are case sensitive; "a" & "A" is different.
  • Only letters, digits, underscore(_), or $ are allowed. (not even space)
  • Only a letter, underscore(_) or $ should be 1st character.
  • Reserved words cannot be variable names.
