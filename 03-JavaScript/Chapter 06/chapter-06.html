Functions in JavaScript

Block of code that performs a specific task, can be invoked/call whenever needed 


     
Function Syntax

     function functionName() {
        // do some work
     }

     
Fuction call

     functionName();

     
Parameter in Function

     function functionName(param1, param2, ...) {
        // do some work
     } 

     functionName("ad", "as");
     // ("ad", "as") these are argument
     // first argument "ad" goes for first param1 second for param2 etc

Arrow Function

Compact way of writing a function


     const functionName = (param1, param2,..) => {
        //do some work
     }

     
Example

     const sum = (a, b) => {
        return a + b;
     }

forEach loop in Arrays

callBackFunction: Here , it is afunction to excute for each element in the array 


     
Syntax

     arr.forEAch(callBackFunction)

A callBack is a function passed as an argument to another function.


     
For Example

     arr.forEach((val) => {

     });

Map (Array Method)

Creates a new array with the results of some operation. The value its callback returns are used to from new array


     
Syntax

     arr.map(callbackFnx(value, index, array));
     
Example

     let newArr = arr.map ((val) => {
        return val * 2;
     });

filter (Array Mehod)

Creates a new array of elements that give true for a condition/filter.

Eg: all even numbers


     let newArr arr.filter ((val) => {
        return val % 2 === 0;
     });

reduce (Array Method)

Performs some operation & reduces the array to a single value. It returns that single value. 


     const array1 = [1, 2, 3, 4];
    
     // 0 + 1 + 2 + 3 + 4
     const initialValue = 0;
     const sumWithInitial = array1.reduce((prev, curr, initialValue) => prev + curr);
     console.log(sumWithInitial);
     expected output 10
