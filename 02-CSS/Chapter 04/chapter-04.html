Chapter 04 — CSS (Casceding Style Sheet)

Display Property

display: inline / block / inline-bock / none

  • inline - Takes only the space required by the element. (no margin/padding).
  • block - Takes full space available in width.
  • inline-block - Similar to inline but we can set margin & padding.
  • none - To remove element from document flow.

Visibility

                    
                        div {
                            Visibility: hidden;
                        }

Note: When visibility is set to none, space for the element is reserved. But for display set to none, no space is reserved or blocked for the element.

Alpha Channel

                    
                        div {
                            color: rgba(255, 0, 0, 0.5);
                            
                            color: rgba(255, 0, 0, 1);
                        }

RGBA Stand For: Red Green Blue Alpha, here alpha means opacity if we set any color using rgb color system and we want that color opacity there we use RGBA system.
