Chapter 05 — CSS (Casceding Style Sheet)

Relative Units in CSS

                    
                        div {
                            width: 100%;
                            max-width: 15em;
                            max-width: 20rem;
                        }

Industry mostly use Relative for layout and font etc

Percentage (%)

                    
                        div {
                            width: 33%;
                            margin-left: 50%;
                            }

It is often used to define a size as relative to an element's parentobject.

Em

Unit Relative to
em Font size of the parent, in the case of typographical properties like font-size, and font size of the element itself, in the case of other properties like width.

Rem (Root Em)

Unit Relative to
rem Font size of the root element.

Others

vh: relative to 1% viewport height

vw: relative to 1% viewport width

Position

                    
                        div {
                            position: static;
                            position: relative;
                            position: absolute;
                            position: fixed;
                            }

The position CSS properly sets how an element is positioned in a document.

Position

  • Static — default position (The top, right, bottom, left, and z-index properties have no effect)
  • relative — element is relative to itself. (The top, right, bottom, left, and z-index will work)
  • absolute — positioned relative to its closest positioned acnestor. (removed from the flow)
  • fixed — positioned relative to browser. (removed from flow)
  • sticky — Positioned based on user's scroll position

z-index

                    
                        div {
                            z-index: auto (0)
                            z-index: 1 / 2 / ...
                            z-index: -1 / -2 / ....
                        }

Background Image

                    
                        div {
                            background-image: url("image.jpeg");
                        }

Background Size

                    
                        div {
                            background-size: cover / contain / auto;
                        }
