Chapter 06 — CSS (Cascading Style Sheet)

Flexbox

Flexible Box Layout

It is one-dimensional layout method for arranging items in rows or columns.

The Flex Model

Flexbox Direction

                
                    div {
                     display: flex;
                     flex-direction: row;  /* (default) */
                     flex-direction: row-reverse;
                     flex-direction: column;
                     flex-direction: column-reverse;
                    }

It sets how flex items are placed in the flex container, along which axis and directioin.

Flex Properties

for Flex Contianer

  • justify-content : alignment along the main axis.

    flex-start / flex-end / center / space-evenly / space-around / space-between

  • flex-wrap : nowrap / wrap / wrap-reverse
  • align-items : alignment along the cross axis
  • align-content : alignment of space between & around the content along cross-axis

Flex Properties

for Flex Item

  • align-self : alignment of individual along the cross axis.

  • flex-grow : how much a flex item will grow relative to the reset of the flex items if space is available
  • flex-shrink : how much a flex item will shrink relatice to the rest of the flex items if space is available
